# Captura de la capa 157 — plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** que la Pi guarde el crudo de la capa 157 (*Estaciones Atmosféricas*)
con las mismas garantías que las demás fuentes: crudo antes de parsear,
convención horaria decidida en cada respuesta, deduplicación por estación y
`--status` que la juzga.

**Architecture:**
- **develop.** Fuente nueva `meteo_estaciones` en `src/project/ingest/sources.py`:
  - parser `parse_meteo`;
  - `resolver_convencion` con un parámetro de agregación;
  - rama nueva en `clave_sondeo`, la función que comparten colector y
    `reprocesar`.
- **`reprocesar`.** Sin `--sources`, deja el clima fuera, así que el stage
  `curar` de DVC sale idéntico byte a byte.
- **raspberry.** Porte a mano a `demo/` (worktree `../TFM-raspberry`). El
  usuario lo despliega en la Pi.

**Tech Stack:** Python 3.11, pandas, httpx, pytest, DVC, uv, ruff. Bash y
systemd en la Pi.

**Spec:** `docs/superpowers/specs/2026-11-07-captura-capa-157-design.md`

## Review Focus

Lo que el spec implica y ningún test del diseño cubría. Cada línea tiene su
test en la Task 2.

1. **Respuesta con `features: []`** (el geoportal la sirve en mantenimiento):
   `parse_meteo` devuelve un DataFrame vacío, sin excepción, y no cuenta como
   sondeo.
2. **Una estación con `fecha_carg` nula**: no rompe el parseo; esa fila sale
   con `ts_utc` NaT y las demás conservan el suyo.
3. **Solo responden las de AEMET** (W01 y W02 calladas): el sondeo sale
   `DUDOSA` y no se descarta.
4. **El servicio de la Pi no se reinicia tras `instalar.sh`**: el proceso viejo
   sigue sin la fuente. Lo cubren la Task 5 (`restart`) y la comprobación de
   `--status` en la Task 6.
5. **El día del solape**: `pull_data.sh --ignore-existing` se salta el fichero
   de la Pi del día D. Se anota en la bitácora (Task 7) para que el segundo
   plan los concatene.

TS_METEO = pd.Timestamp("2026-11-06T17:39:20.584987Z")


def _meteo(fix: dict, desplazar_ms: int = 0) -> dict:
    p = copy.deepcopy(fix["meteo_estaciones"])
    for f in p["features"]:
        f["attributes"]["fecha_carg"] += desplazar_ms
    return p


def test_meteo_decide_la_convencion_con_la_fila_mas_fresca(fix):
    """Las de AEMET llegan con 51-91 min de retraso: con la mediana, ninguna
    lectura cuadra y sale DUDOSA siempre. La más fresca (W01, 17:30Z) sí."""
    d = parse("meteo_estaciones", _meteo(fix), TS_METEO)
    assert len(d) == 5
    assert (d["tz_convencion"] == "YA_EN_UTC").all()
    esperado = pd.to_datetime(d["fecha_carg"], unit="ms", utc=True)
    assert (d["ts_utc"] == esperado).all()
    assert d["latencia_s"].min() == pytest.approx(560.584987)


def test_meteo_servida_en_hora_local_da_los_mismos_ts_utc(fix):
    """Mismo dato sellado en hora de pared de invierno (CET, +1 h)."""
    utc = parse("meteo_estaciones", _meteo(fix), TS_METEO)
    loc = parse("meteo_estaciones", _meteo(fix, 3_600_000), TS_METEO)
    assert (loc["tz_convencion"] == "LOCAL_NAIVE").all()
    assert (loc["ts_utc"] == utc["ts_utc"]).all()


def test_meteo_sin_las_municipales_sale_dudosa(fix):
    p = _meteo(fix)
    p["features"] = [
        f for f in p["features"] if not f["attributes"]["fiwareid"].startswith(("W01", "W02"))
    ]
    d = parse("meteo_estaciones", p, TS_METEO)
    assert len(d) == 3 and (d["tz_convencion"] == "DUDOSA").all()


def test_meteo_sin_features_devuelve_vacio(fix):
    assert parse("meteo_estaciones", {"features": []}, TS_METEO).empty


def test_meteo_una_estacion_sin_fecha_no_rompe_las_demas(fix):
    p = _meteo(fix)
    p["features"][0]["attributes"]["fecha_carg"] = None
    d = parse("meteo_estaciones", p, TS_METEO)
    assert d["ts_utc"].isna().sum() == 1
    assert (d["tz_convencion"] == "YA_EN_UTC").all()
